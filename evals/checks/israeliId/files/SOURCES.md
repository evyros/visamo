All made up for the evals, for a made-up person: Noa Levi, the scenarios'
Israeli partner (ID number 314826579, made up, with a valid check digit).
Rendered from HTML with headless Chrome, so they're clean and straight.

- id-card.pdf: both sides of a biometric Teudat Zehut on one page, as
  scanned: the front with the photo, names, dates and ID number; the back
  with the parents' names, place of issue, chip and machine-readable lines.
  Issued 07.05.2023, valid to 07.05.2033.
- appendix-single.pdf: the appendix (ספח) as downloaded from the personal
  area on gov.il, produced 14/09/2026: civil status רווקה (single), address
  in Tel Aviv, no spouse, no children.
- appendix-married.pdf: the same appendix, civil status נשואה (married)
  since 21/06/2025, with the spouse (John Smith, US) listed.

The appendices are produced 14/09/2026, two weeks before the cases' fixed
date (2026-10-01), so they're recent.
