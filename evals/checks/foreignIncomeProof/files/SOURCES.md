# Where these files come from

The estonia-2026-*.pdf files are English translations of real Estonian
payslips (palgateatis) from L'DOLCEVITA OÜ, shared by the app's owner: one
for September and one for October 2026, and two statements for August 2026,
the base earnings and the same month again with the vacation pay added.
Only the translations are here, not the Estonian originals: a translation
alone isn't enough, so the case expects the check to ask for them.
